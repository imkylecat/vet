TupleSchema

Validates a fixed sequence where each position has its own schema. Use it for packed argument lists and other positional payloads, where ArraySchema would only let you say that every element is the same shape.

Like ArraySchema, the input is returned untouched unless a position fills a value in, in which case it is shallow copied first. 

local Waypoint = v.tuple({ v.string(), v.number():integer() })

Waypoint:parse({ "spawn", 3 }) --> { "spawn", 3 }
Waypoint:parse({ "spawn" })    --> errors: [2]: expected number, got nil
Waypoint:parse({ "a", 1, 2 })  --> errors: expected a tuple of 2 values, got 3

A position whose schema is optional or has a default may be left off the end, since Lua cannot tell a trailing nil from a shorter list: 

local Ping = v.tuple({ v.string(), v.number():default(0) })

Ping:parse({ "hello" }) --> { "hello", 0 }

Like :default, but calls produce on every parse instead of reusing one value. Prefer it here, since a single table would otherwise be shared by every caller and mutable through any of them.

The produced value is validated each time.

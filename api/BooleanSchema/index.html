BooleanSchema

Validates booleans. Truthy values that are not booleans, such as 1 or "true", are rejected. 

local Enabled = v.boolean()

Properties​

isOptional​

This item is read only and cannot be modified. Read OnlyReflection
</>
BooleanSchema.isOptional: boolean

Always false. Booleans carry no minimum or maximum, since neither means anything for two values.

defaultWith​

Wrapper
</>
BooleanSchema:defaultWith(
produce: () → boolean--

Builds the value used when parsing nil

) → DefaultSchema<boolean>

Like BooleanSchema:default, but calls produce on every parse instead of reusing one value. Use it when the fallback is a table, since a single table would otherwise be shared by every caller and mutable through any of them.

The produced value is validated each time, so a producer that returns something invalid fails at parse rather than silently passing through.

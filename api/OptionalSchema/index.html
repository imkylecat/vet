OptionalSchema

Accepts nil in addition to whatever the wrapped schema accepts. Created by calling :optional() on any schema, which comes last in a chain so that the refinements before it still apply to non-nil values. 

local Nickname = v.string():max(20):optional()

Nickname:parse(nil)        --> nil
Nickname:parse("kyle")     --> "kyle"
Nickname:parse(5)          --> errors

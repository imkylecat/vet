DatatypeSchema

Validates a Roblox datatype by its typeof name, so a table that merely carries the same fields is rejected — useful when the value arrived over a remote, where anything can be sent.

Reached through the named constructors rather than built directly: Vet.color3 and Vet.udim2 both return one of these. 

local Tint = v.color3()
local Size = v.udim2()

Tint:parse(Color3.new(1, 0, 0))      --> Color3(1, 0, 0)
Tint:parse({ R = 1, G = 0, B = 0 })  --> errors: expected Color3, got table
Size:parse(UDim2.fromScale(1, 1))    --> UDim2

Each datatype schema holds no state beyond the name it checks, so the constructors hand out one frozen shared instance rather than allocating.
